Звіт до лабораторної 2 «Перша сторінка»
Студент: Кравець Арсен, ІПЗ 3/2

Що зроблено
Створив папку C:\webdev\kravets\taskboard, сторінку index.html зі структурою HTML5 (DOCTYPE, html lang="uk", head з meta charset і title, body) та папку images з логотипом. Сторінку відкривав через розширення Live Server у VS Code.

Запити в Network
| Файл | Метод | Статус | Тип | Розмір файлу |
|------|-------|--------|-----|--------------|
| index.html | GET | 200 | document | 536 B |
| logo.png | GET | 200 | png | 26,6 kB |

Коли в src написав images/logo1.png, запит до картинки став червоним зі статусом 404, а на сторінці лишився тільки текст з alt.

Відповіді
1. Адреса: http://127.0.0.1:5500/index.html. Протокол http, хост 127.0.0.1 (це мій комп'ютер), порт 5500, на якому слухає Live Server, і шлях /index.html.
2. Основних запитів два: спочатку сама сторінка, а коли браузер дійшов до тегу img, окремо завантажив logo.png. На кожен файл, що потрібен сторінці, браузер робить свій запит.
3. Неправильний шлях дав помилку 404: сервер такого файлу не знайшов, тому браузер показав замість картинки альтернативний текст.
4. У DevTools я змінював тільки DOM, тобто копію сторінки в пам'яті браузера. Після F5 сторінка знову прийшла з сервера з диска, тому мої зміни зникли.
5. Клієнт — це браузер, який робить запити. Сервер — Live Server на моєму ж комп'ютері, який відповідає на них файлами з папки проєкту.


Звіт до практичної 6 «Git у терміналі»
Студент: Кравець Арсен, ІПЗ 3/2

Репозиторій створив командою git init -b main. Ім'я й пошту автора прописав лише для цього проєкту (git config без --global).

1. Що змінилося у виводі git status після git add?
Файл index.html перемістився з червоного списку Untracked files у зелений розділ Changes to be committed. Решта файлів лишилась невідстежуваною, бо я додав в індекс тільки один файл.

2. Що показує git diff?
Він порівнює робочі файли з останнім комітом і показує рядки, що змінились: додані позначені плюсом, видалені мінусом. Коли я прибрав </html>, саме цей рядок з'явився червоним з мінусом.

3. Чим відрізняється git switch main від git merge?
switch просто перемикає мене на іншу гілку: робоча папка стає такою, як у main, тому about.html тимчасово зник. merge забирає коміти з гілки about-page у поточну, і після нього файл з'явився в main уже назавжди.

4. Чому виник конфлікт і як ти його розв'язав?
Обидві гілки змінили той самий рядок із заголовком h1, і Git не міг сам вибрати правильний варіант. Я прибрав маркери <<<<<<<, ======= і >>>>>>> та залишив об'єднаний заголовок «Дошка завдань TaskBoard», після чого зробив add і commit.

5. Скільки commit-ів у твоїй історії?

Додаткове завдання
- У гілці experiment прибрав з головної рядок автора і посилання на MDN, закомітив. Звичайне git branch -d гілку не видалило, бо вона не злита, тому видалив через git branch -D. У main усе лишилось на місці, git status — чисто.
- git log --oneline -- index.html показав 5 комітів: тільки ті, що змінювали саме цей файл.
