Студент: Кравець Арсен, ІПЗ 3/2

Що зроблено
Створив папку C:\webdev\kravets\taskboard, сторінку index.html зі структурою HTML5 (DOCTYPE, html lang="uk", head з meta charset і title, body) та папку images з логотипом. Сторінку відкривав через розширення Live Server у VS Code.

Запити в Network
| Файл | Метод | Статус | Тип | Розмір файлу |
|------|-------|--------|-----|--------------|
| index.html | GET | 200 | document | 536 B |
| logo.png | GET | 200 | png | 26,6 kB |

Коли в src написав images/logo1.png, запит до картинки став червоним зі статусом 404, а на сторінці лишився тільки текст з alt.

Відповіді
1. Адреса: http://127.0.0.1:5500/index.html. Протокол http, хост 127.0.0.1 (це мій комп'ютер), порт 5500, на якому слухає Live Server, і шлях /index.html.
2. Основних запитів два: спочатку сама сторінка, а коли браузер дійшов до тегу img, окремо завантажив logo.png. На кожен файл, що потрібен сторінці, браузер робить свій запит.
3. Неправильний шлях дав помилку 404: сервер такого файлу не знайшов, тому браузер показав замість картинки альтернативний текст.
4. У DevTools я змінював тільки DOM, тобто копію сторінки в пам'яті браузера. Після F5 сторінка знову прийшла з сервера з диска, тому мої зміни зникли.
5. Клієнт — це браузер, який робить запити. Сервер — Live Server на моєму ж комп'ютері, який відповідає на них файлами з папки проєкту.
